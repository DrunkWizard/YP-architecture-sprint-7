### Оценка рисков
Виды рисков:
- Утечка данных  
Когда доступ к данным получает лицо, которое не должно было иметь к ним доступ. Например когда злоумышленник обнаружил уязвимость и смог получить доступ к внутренней БД или средствами социальной инженерии узнал данные для входа под чужой учетной записью.
- Потеря данных  
Когда важные данные удаляются без возможности восстановления. Например разработчик с доступ к базам на продакшн инфраструктуре выполнил неверный запрос на удаление данных на которые не было бэкаров.
- Искажение данных  
Когда данные не соответствуют действительности 
- Некачественные данные  
Данные лежат в неудобном виде или содержат ошибки
- Обесценивание данных  
Хранение данных, которые потеряли свою аткуальность и не имеют никакой ценности для бизнеса. 


#### Публичные данные 
Риски:
- Потеря данных  
Потеря данных об объектах на витрине может снизить продажи.   
Уровень критичности - незначительный
- Искажение данных    
Неверные данные об объектах могут снизить лояльность и продажи.  
Уровень критичности - значительный  
- Некачественные данные  
Ошибки на витрине ухудшают маркетинговую воронку, могут привети к потери репутации и снижению уровня продаж.  
Уровень критичности - значительный
- Обесценивание данных
Устаревшие данные о недвижимости могут снизить лояльность клиентов.  
Уровень критичности - незначительный


#### Внутренние данные
Риски:
- Утечка данных  
Утечка технических логов и метрик может позволить злоумышлинкам получить дополнительную информацию для дальнейших атак.
Также это может плохо повлиять на репутацию компании если внутренние данные окажутся скомпрометированны.   
Уровень критичности - значительный
- Потеря данных  
Потеря внутренних данных может привести к проблемам по диагностие инцидентов.  
Уровень критичности - значительный
- Искажение данных  
Может привести к неверной интерпретации состояния системы, искаженым прогнозам аналитиков.  
Уровень критичности - значительный
- Некачественные данные  
Сложнее проводить диагностику.  
Уровень критичности - незначительный
- Обесценивание данных  
Траты ресурсов на хранение неактуальный информации.  
Уровень критичности - незначительный

#### Конфиденциальные данные 
Риски:
- Утечка данных  
Большие репутационные риски в случае утечки данных пользовтелей, штрафы.  
Уровень критичности - критический
- Потеря данных  
Потеря репутации, проблемы с заказами и юридической стороной сделок.  
Уровень критичности - критический
- Искажение данных  
Юридические проблемы с оформлением сделок.  
Уровень критичности - критический
- Некачественные данные 
Сложнее поддержка и диагностика инцидентов.  
Уровень критичности - значительный
- Обесценивание данных  
Во время не обновленные персональные данные клиентов могут привести к юридическим проблемам.  
Уровень критичности - значительный

#### Секретные данныеРиски:
- Утечка данных  
Утечка секретных ключей может привести к утечке всей информации сервиса, получению полного доступа злоумышлеников к инфраструктуре.  
Уровень критичности - критический
- Потеря данных  
Потеря данных о сделке может привести к искам и большим убыткам. Потеря ключей может привести к восстановительным работам.  
Уровень критичности - критический
- Искажение данных  
Подмена данных сделок может привести к искам и большим убыткам.  
Уровень критичности - критический
- Некачественные данные  
Ошибки в секретах могут привести к срыву сделок, искам и отказам в сотрудничестве.  
Уровень критичности - критический
- Обесценивание данных 
Во время не обновленные ключи могут привести к восстановительным работам.   
Уровень критичности - значительный
