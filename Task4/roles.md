| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| cluster-admin | Полный доступ ко всем ресурсам кластера. | Администраторы кластера. |
| developer | Чтение и запись большинства ресурсов (кроме RBAC, секретов) в назначенных namespace | Разработчики, которым нужно деплоить приложения |
| auditor-view | Только чтение ресурсов (кроме секретов) во всех namespace | Аналитики, команда безопасности | 
| secret-manager | Чтение и управление секретами в назначенных namespace | Команда безопасности, специальные сервисные аккаунты |
