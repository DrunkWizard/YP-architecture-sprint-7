## Проверочный лист безопасности для PropDevelopment

Компания сталкивается с проблемами в области:

- Управления доступом (разрозненные системы, утечки данных между ЖКХ).
- Безопасности данных (неконтролируемые потоки данных, проблемы с персональными данными).
- Защиты инфраструктуры (гибридное развертывание, уязвимости API партнёров).
- Управления инцидентами (недавние утечки у конкурентов, необходимость соответствия законодательству).

Основные риски:

- Утечки персональных данных (клиенты видят чужие данные в ЛК).
- Несоответствие законодательству (ФЗ-152, GDPR при работе с партнёрами).
- Небезопасные API (доступ к данным других управляющих компаний).
